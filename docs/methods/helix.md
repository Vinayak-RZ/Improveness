# HELIX

**Paper:** [arXiv:2608.13951](https://arxiv.org/abs/2608.13951)

Host-agnostic agent runtime ideas. Improveness takes **one** piece: a thin **HostPort**, not a second kernel inside DeepSeek Harness.

If HostPort grows a process supervisor, a second permission system, or a second model router, it has stopped being HELIX-thin.
